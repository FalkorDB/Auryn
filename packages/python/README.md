# auryn-python

Python language plugin for Auryn: fast `ast` + deep Jedi (in-process) engines, plus the web-framework route enrichment.

Part of [Auryn](https://github.com/FalkorDB/Auryn), which turns a codebase into a queryable knowledge graph for AI agents.

## Install

```bash
pip install falkordb-auryn                  # Auryn with every plugin
pip install "auryn-core[python]"            # Auryn with only this plugin
```
