# auryn-typescript

TypeScript/JavaScript language plugin for Auryn: one fast tree-sitter engine over the whole JS/TS family (.ts/.tsx/.js/.jsx/.mjs/.cjs), extracting classes/interfaces/enums/type-aliases/functions/methods/params, the ES-module import graph, and calls. A deep tsserver/TS-compiler pass (resolved types, cross-module calls) is the planned second phase.

Part of [Auryn](https://github.com/FalkorDB/Auryn), which turns a codebase into a queryable knowledge graph for AI agents.

## Install

```bash
pip install auryn-typescript
```

To install Auryn with every language plugin, use `pip install falkordb-auryn`.
