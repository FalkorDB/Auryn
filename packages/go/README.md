# auryn-go

Go language plugin for Auryn: a fast tree-sitter-go engine extracting packages/structs/interfaces/functions/methods/fields/params/consts, Go embedding (EMBEDS), and calls. IMPLEMENTS (structural interface satisfaction) and precise cross-file type resolution are the planned deep pass (a go/types or gopls-backed engine).

Part of [Auryn](https://github.com/FalkorDB/Auryn), which turns a codebase into a queryable knowledge graph for AI agents.

## Install

```bash
pip install auryn-go
```

To install Auryn with every language plugin, use `pip install falkordb-auryn`.
