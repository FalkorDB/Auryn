# auryn-csharp

C# language plugin for Auryn: fast tree-sitter parse + deep Roslyn extractor (bundled source, built on demand; requires the .NET SDK).

Part of [Auryn](https://github.com/FalkorDB/Auryn), which turns a codebase into a queryable knowledge graph for AI agents.

## Install

```bash
pip install falkordb-auryn                  # Auryn with every plugin
pip install "auryn-core[csharp]"            # Auryn with only this plugin
```
