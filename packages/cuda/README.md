# auryn-cuda

CUDA language plugin for Auryn: reuses the auryn-cpp engine and adds kernel execution-space and kernel-launch (LAUNCHES) signals.

Part of [Auryn](https://github.com/FalkorDB/Auryn), which turns a codebase into a queryable knowledge graph for AI agents.

## Install

```bash
pip install falkordb-auryn                  # Auryn with every plugin
pip install "auryn-core[cuda]"              # Auryn with only this plugin
```
