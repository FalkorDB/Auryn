# auryn-kotlin

Kotlin language plugin for Auryn: a fast tree-sitter-kotlin engine extracting packages/classes/objects/interfaces/enums/methods/functions/fields/params, the type hierarchy (EXTENDS/IMPLEMENTS), and calls. A deep pass (Kotlin compiler / kotlin-language-server symbol resolution) is the planned second phase.

Part of [Auryn](https://github.com/FalkorDB/Auryn), which turns a codebase into a queryable knowledge graph for AI agents.

## Install

```bash
pip install auryn-kotlin
```

To install Auryn with every language plugin, use `pip install falkordb-auryn`.
